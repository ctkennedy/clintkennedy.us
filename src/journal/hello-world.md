This is the first entry in my journal. I built this site because I wanted a place on the web that I own completely — no algorithms, no tracking, no platform risk.

Everything here is available via RSS, JSON Feed, and the open web. You can subscribe with any feed reader, follow along from the Fediverse, or just bookmark the URL and come back when you feel like it.

The site runs on Eleventy, deploys through GitHub to Netlify, and uses nothing but plain HTML, CSS, and Markdown. No JavaScript required to read anything here. The fonts are Courier because the early web got that part right.

More to come.
