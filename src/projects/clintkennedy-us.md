This site itself is the first project. It's a static site built with Eleventy, styled with plain CSS using monospace fonts, and deployed to Netlify via GitHub.

## Stack

- **Eleventy** for static site generation
- **Nunjucks** for templating
- **Markdown** for content
- **Netlify** for hosting and deployment
- **GitHub** for version control

## Features

- RSS/Atom feeds for every section
- JSON Feed support
- ActivityPub discovery via WebFinger
- IndieWeb microformats (h-entry, h-card, h-feed)
- No JavaScript required to read content
- Fully responsive, black and white design
